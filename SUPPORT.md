## Response Times

| Type | Expected Response |
|------|-------------------|
| **Bug reports** | 1-3 business days |
| **Feature requests** | 1-2 weeks |
| **Performance issues** | 3-5 business days |
| **Security reports** | 24-48 hours |
| **General questions** | 1-2 weeks |

## Supported Versions

| Version | Supported |
|---------|-----------|
| **Latest release** | ✅ Yes |
| **Previous minor** | ✅ Best effort |
| **Older versions** | ❌ No |

## System Requirements

- **OS**: Windows 10/11 (x64)
- **Go**: 1.22+ (for building from source)
- **Disk**: ~50MB for binaries
- **RAM**: 512MB minimum recommended
